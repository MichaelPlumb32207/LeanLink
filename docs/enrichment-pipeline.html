1. Ingest filter (what “NPA + ACT” means)

Not “politically active voters.” ACT is the Florida DOS registration status code on field 28 of the voter extract: ACT = active on the rolls, INA = inactive. Default ingest keeps NPA (no party affiliation) + ACT only, plus excludes suppressed / public-records-exempt rows (DEFAULT_LEANLINK_FILTER in lib/fl-voter-registration.ts).

That filtered set is the working upload — typically hundreds to tens of thousands per county, not the full raw extract.

10. How to evaluate

  1. Apply migrations 005 + 006 on Neon (scripts/check-migrations.ts).
  2. Import FL contrib: download-fl-contrib.ts → import-fl-contrib-dir.ts.
  3. Import Sunbiz: SFTP cordata.zip → import each cordata0.txt–cordata9.txt via import-sunbiz-cor.ts.
  4. Upload county file → confirm NPA+ACT count.
  5. FEC sweep ($0) → Run free pass (dashboard or run-free-pass.ts).
  6. In Evidence accumulator: toggle FEC✓, Layer-2, or Sunbiz filters (or combine with name search) to scan labeled donors, entity-bridge rows, and officer matches.
  7. Paid OSINT only on curated subset after Free Pass review.
